How it reads

Tamal writes each Malayalam word the way a Tamil reader would say it, for example:

  • അത് → அது: the half-u at the end of a word
  • ഭാരതം → பாரதம்: Tamil has one letter for ബ, ഭ and പ
  • ടിക്കറ്റ് → டிக்கட்டு: double letters in the usual Tamil spelling

It changes the script, not the language: this is transliteration, not translation.
